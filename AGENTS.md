# Documentation

Apply this paragraph rule throughout the repository: split prose paragraphs longer than 150 words at topic boundaries,
aiming for 80–150 words per resulting paragraph. Keep shorter paragraphs concise; do not pad summaries, instructions, or
list items to reach 80 words. Tables and code blocks are not prose paragraphs.

Keep README files and CONTRIBUTING.md short, linking to the hosted Read the Docs guides. Maintain installation, usage,
and contribution instructions under `website/content/`. Format Markdown with `mdformat --wrap 120` after editing it.

Provider setup

Sign in with the provider's client, enable the provider in Quotaline Settings, then select its refresh button. The app reads existing local credentials and does not ask for passwords. Connection details in Settings shows the credential source currently in use.

Claude

Run claude auth login in a terminal. The service reads ~/.claude/.credentials.json, or the same file under CLAUDE_CONFIG_DIR when that variable is set. Local transcript totals work without online credentials.

Codex

Run codex login in a terminal. The service checks its Secret Service item and ~/.codex/auth.json, using CODEX_HOME when set. Recent CLI rollout files can supply a stale quota reading while online access fails.

Gemini CLI

Run gemini in a terminal and sign in with Google. The service reads ~/.gemini/oauth_creds.json, using GEMINI_CLI_HOME when set. When GEMINI_FORCE_ENCRYPTED_FILE_STORAGE=true is set for both Gemini CLI and the service, it reads the Gemini Secret Service item first.

Antigravity

Sign in through the Antigravity app. The service first checks the same-user local language server. Its cloud fallback can read the Antigravity Secret Service item, the CLI credential file under ~/.gemini/antigravity-cli/, ~/.config/Antigravity/auth.json, or ANTIGRAVITY_AUTH_FILE.

Cursor

Sign in through Cursor or run cursor-agent login. The service reads the app session from Cursor's XDG state.vscdb first, then ~/.cursor/auth.json. It asks for a new sign-in when a session is within two minutes of expiry.

GitHub Copilot

Run copilot login or sign in through a supported Copilot client. The service can read a token from the environment, the copilot-cli Secret Service item, ~/.copilot/config.json, or XDG editor credentials. It does not change those credentials.

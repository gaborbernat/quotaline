# macOS

This directory contains the Swift app, its native integrations, and its tests. Shared provider rules and storage live in
the workspace's Rust crates. See the [architecture guide](../website/content/contributing/architecture.md) for the
boundary between them.

The [install guide](../website/content/start/_index.md) lists the current download channels. The
[build guide](../website/content/contributing/build.md) covers locked tools and local checks.

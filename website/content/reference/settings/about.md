- **Version** identifies the source build and distribution channel.
- **Privacy Policy** opens the [privacy policy](/explanation/privacy/) in your default browser.
- **Acknowledgements**, beside it, opens the [notices](/explanation/notices/): the trademark statement and the license
  of the icon set behind the provider marks.
- **Launch at login** registers the macOS app. **Open Login Items**, on the same row, opens the approval pane. On GNOME,
  enabled extensions load at sign-in; **Open Extensions** opens the extension manager.
- **Demo data** starts off. It relaunches with generated providers; turn it off to return to your accounts.
- Release Direct builds on macOS show **Check for updates automatically**, with **Check for Updates** in the footer. App
  Store, Homebrew and local development bundles omit update controls; the GNOME extension has no in-app updater.

**Copy Diagnostics** and **Source** sit in the Settings footer, with icons. **Report Issue**, **Refresh** and **Quit**
remain in the footer. Review diagnostics before sharing them; [privacy](/explanation/) describes their contents.

There is one **Reset All Settings** button at the end of Settings, with confirmation. It resets preferences, including
provider choices and access grants. It does not sign you out of the provider clients or clear history; use **Clear…**
under Data for that.
